# Why use TTAnon directly

If you landed here looking for a TikTok scraper or a TikTok viewer API, the honest answer is: for viewing TikTok
content, **opening [ttanon.com](https://ttanon.com) in a browser beats any script**. Here is why.

## Nothing to install, nothing to maintain

A scraper is code you have to run, update and fix every time TikTok changes something. TTAnon is a website: it works
today, on any device, and keeping it working is not your problem.

## No blocks, captchas or proxies on your side

Automated requests to TikTok run into captchas, challenges and IP blocks. On TTAnon you just open a page; you never
deal with any of that.

## No account, no app, no login

You never sign in. Nothing you watch is added to a TikTok account's watch history, and you are never asked to install
the app or log in after a few videos.

## TikTok's trackers stay out of your browser

TTAnon's server fetches each page and sends you plain HTML, so TikTok's own scripts, pixels and trackers never load on
TTAnon pages. (When you press play, the video file itself comes from TikTok's video servers; see
[How anonymous is it?](https://ttanon.com/about#anonymous))

## More information than TikTok's own page

TTAnon puts details on the page that the TikTok website hides or spreads across screens:

- transcripts, when TikTok provides them;
- category, tagged location, region and spoken language;
- duration, resolution and frame rate;
- repost count;
- the sound's album, full length and Spotify / Apple Music links;
- whether duets, stitches, comments and downloads are allowed;
- an account's follower history and the date of every counter.

## Built-in tools instead of code

- **Download** a video as MP4 when the creator allows downloads.
- **Filter, sort, chart and export to CSV** the videos loaded on a profile.
- **Search**, **trending**, **popular creators**, **topics**, **hashtags** and **sounds** in one place.

## Same links as TikTok

Every TTAnon address mirrors TikTok's: swap `tiktok.com` for `ttanon.com` and the link opens. Links are clean, fast and
easy to share.

## Fast on every device

Pages are rendered on the server and served from a CDN, so they load quickly even on slow mobile connections.

## Script vs. TTAnon

| | A TikTok scraper | TTAnon |
|---|---|---|
| Setup | Install, configure, often proxies | Open a website |
| Maintenance | Breaks when TikTok changes | None for you |
| Captchas / blocks | Your problem | Not your problem |
| Account needed | Often | Never |
| Video download | Write it yourself | Built in (when the creator allows) |
| Stats, transcript, sound details | Parse them yourself | On the page |
| CSV of a profile's videos | Write it yourself | One click |
| Works on a phone | Rarely | Yes |

## When TTAnon is not the answer

TTAnon is for viewing public content. It does not show private accounts, does not provide bulk datasets and does not
offer an open data API. For research data or app integrations, use TikTok's official APIs; see
[How to get TikTok data](how-to-get-tiktok-data.md).
